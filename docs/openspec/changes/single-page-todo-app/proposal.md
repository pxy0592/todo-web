## Why

当前仓库只有项目与 OpenSpec 脚手架，没有可供用户直接管理任务的界面。需要先提供一个轻量、无需后端的单页 Todo 基础能力，让任务创建、完成、删除和刷新后恢复成为可验证的产品闭环，并为后续筛选、优先级等能力保留清晰扩展边界。

## What Changes

- 新增单页 Todo 应用界面。
- 提供任务文本输入框和“添加”按钮，支持创建任务。
- 以列表行展示任务文本、完成复选框和“删除”按钮。
- 通过复选框切换任务完成状态，并以删除线等视觉样式区分已完成任务。
- 使用浏览器 `localStorage` 保存任务数据，页面刷新后恢复。
- 将任务模型、持久化逻辑和界面交互分层，便于未来加入筛选或优先级。

## Capabilities

### New Capabilities

- `todo-management`: 管理任务的创建、展示、完成、删除及浏览器本地持久化。

### Modified Capabilities

无。

## Impact

影响尚未建立的前端应用代码、页面样式和浏览器端存储逻辑；不新增后端 API 或服务端数据库。实现时需要补充前端运行、构建和自动化测试工具链，并覆盖核心交互与刷新恢复场景。
